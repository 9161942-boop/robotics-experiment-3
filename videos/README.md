# 实验三演示视频

本目录保存实验三的两段 Gazebo 运行录屏和一段实体机械臂现场演示：

- `experiment3_gazebo_sorting_run_01.webm`：第一段仿真演示。
- `experiment3_gazebo_sorting_run_02.webm`：第二段仿真演示。

视频用于补充报告中的场景、抓取、搬运和分类过程证据；对象级结果以 `evidence/mecharm_sorting_execution.csv` 为准。

`experiment3_real_robot_grasp_demo.mp4` 为 2 分 12 秒的实体机械臂现场视频；约 01:22 的画面可见夹爪夹持黄色小锁并抬离桌面。它用于复核真实夹爪与桌面物体的动作，不作为六目标自动分类成功率的统计依据。关键帧另存于 `evidence/real_robot_grasp_frame_82s.png`。
